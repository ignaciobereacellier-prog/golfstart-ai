# Branding de GolfStart AI (provisional)

> Valores provisionales para empezar el prototipo. Ignacio los sustituye por los definitivos y luego se aplican con el paso 7 de `PROMPTS.md`.

- **Nombre:** GolfStart AI
- **Eslogan:** Empieza a jugar al golf de forma fácil e inteligente.
- **Estilo:** moderno, limpio y juvenil, con algún guiño al golf tradicional. Pocos elementos por pantalla y mucho aire.
- **Tono:** cercano y sencillo; los términos de golf siempre explicados.

## Colores provisionales
| Uso | Color | Hex |
|---|---|---|
| Principal (botones, cabecera, barra de navegación) | Verde campo | `#1B5E3B` |
| Fondo | Blanco roto, como la arena clara | `#F7F5EF` |
| Superficies suaves (tarjetas, mensajes del asistente) | Verde green claro | `#DDEFE3` |
| Acento (insignias, puntos, retos) | Amarillo bandera | `#F2B705` |
| Texto | Casi negro | `#1E1E1E` |

- El amarillo va solo de fondo (insignias, etiquetas de puntos) y siempre con texto oscuro encima, nunca como color de texto sobre blanco.
- Sobre el verde campo, texto en blanco.
