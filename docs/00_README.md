# GolfStart AI — Proyecto TFM y aplicación

**Estado:** especificación inicial para desarrollo; no se afirma que exista una app funcional ni que se hayan realizado pruebas.

## Propósito
Asistente de inteligencia artificial para personas de 18 a 30 años que comienzan a jugar al golf. Responde preguntas básicas, ofrece una guía, organiza entrenamientos adaptados y motiva mediante retos y puntos.

## Documentos
- `01_producto_y_usuarios.md`: problema, propósito, público y negocio.
- `02_branding.md`: identidad visual, tono, logotipo y sistema de diseño.
- `03_funcionalidades_y_mvp.md`: alcance, historias de usuario y prioridades.
- `04_experiencia_y_pantallas.md`: navegación, pantallas y recorridos.
- `05_arquitectura_codex.md`: tecnología, datos, API y seguridad.
- `06_ia_y_contenidos.md`: asistente, prompts, fuentes y 20 preguntas.
- `07_gamificacion.md`: niveles, puntos, desafíos y antiabuso.
- `08_pruebas_y_metricas.md`: protocolo de evaluación y métricas.
- `09_tfm_estructura_y_pendientes.md`: estructura de 15–45 páginas y trabajos pendientes.
- `10_plan_de_implementacion.md`: hitos, criterios de aceptación y prioridades.
- `11_instrucciones_para_codex.md`: instrucciones copiables para construir el MVP.
- `12_guion_video.md`: propuesta de vídeo de máximo 3 minutos.

## Orden de trabajo
1. Leer los documentos 01–11.
2. Construir primero el MVP: onboarding, chat, guía, planes, progreso y puntos.
3. Probar respuestas y flujos con usuarios antes de afirmar resultados.
4. Preparar el PDF del TFM y grabar el vídeo.

**Fuera del MVP:** avatar 3D interactivo, análisis automático del swing y pagos reales. Se podrán añadir más adelante.
